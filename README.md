# AgentSiteOps

Live site: https://agentsiteops.com

AgentSiteOps is a small manual decision system for AI-capable solo builders who need to choose one sellable first offer, one landing-page route, and one short validation path before building more pages or software.

## Current Status

- Public self-score: 52/100.
- Technical status: launchable.
- Commercial status: unvalidated until confirmed payment plus usable intake exists.
- Payment path: PayPal-hosted links only.
- No guarantees: no promised traffic, rankings, AI citations, customers, revenue, or payback.

## Exposure Sprint

The current sprint is intentionally short: 48 hours. The goal is not broad traffic. The goal is to obtain the first measurable signal from public discovery, GitHub inspection, source-link clicks, sample views, qualified replies, payment clicks, confirmed payments, usable intake, or objections.

If the first exposure loop produces attention without qualified replies, sample views, or useful objections, the offer should be rewritten before more pages are added.

## Repository Boundary

Do not store private customer names, emails, handles, payment identifiers, bank details, account screenshots, or private replies in this repo. Public records should use aggregate counts only.
