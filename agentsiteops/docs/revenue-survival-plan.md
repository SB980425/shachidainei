# Revenue Survival Plan

Date: 2026-06-07

## Objective

Prepare the site to cover ongoing AI execution cost, including future Codex / ChatGPT Pro usage, without relying on early advertising revenue.

Current external pricing references:

- OpenAI ChatGPT pricing page lists Pro at USD 200 per month.
- OpenAI Help Center describes Pro USD 100 and Pro USD 200 tiers, with Pro USD 200 as the highest usage tier.

The operating target for this project is therefore:

| Target | Amount |
|---|---:|
| Minimum monthly AI reserve | USD 100 |
| Preferred monthly AI reserve | USD 200 |
| 3-month preferred reserve | USD 600 |

## Cost Model

| Item | Phase 1 cost | Notes |
|---|---:|---|
| Domain | USD 10-20 per year | Required for production credibility. |
| GitHub | USD 0 | Free is enough at launch. |
| Cloudflare Pages | USD 0 | Static assets can be hosted without monthly cost. |
| Vercel Pro | USD 20 per month if selected | Use only if commercial deployment requires it. |
| Cloudflare Web Analytics | USD 0 | Good enough for phase 1 traffic visibility. |
| Google Search Console | USD 0 | Required for indexing and search evidence. |
| Bing Webmaster Tools | USD 0 | Required for Bing and AI-adjacent visibility signals. |
| Payment platform | USD 0 monthly, transaction fees apply | Use only after service or template demand is confirmed. |
| Codex / ChatGPT Pro reserve | USD 100-200 per month | Must be funded by revenue or investor support. |

## Revenue Order

### Phase 1: Audit Service

Primary offer test:

- AI Website Opportunity Audit
- Price test: USD 49-99 after a request exists
- Delivery: one scored opportunity, risk summary, 30-day validation plan, and repo/action backlog
- Reason: fastest route to cash if the buyer has inspected a public sample and still needs a decision.
- Current boundary: no checkout until sample report, free readiness tool, identity, terms, refund policy, and payment support are ready.

Break-even:

| Goal | Needed at USD 49 | Needed at USD 99 |
|---|---:|---:|
| USD 100 monthly reserve | 3 audits before fees and refunds | 2 audits before fees and refunds |
| USD 200 monthly reserve | 5 audits before fees and refunds | 3 audits before fees and refunds |

### Phase 2: Template Bundle Waitlist

Secondary offer:

- AI Website Launch Operating Kit
- Price test: USD 29-49
- Contents: opportunity scorer, SEO repo skeleton, AI content gate, pSEO gate, technical SEO CI checklist, 30-day review sheet
- First step: waitlist or request-access page, not immediate payment.

Break-even:

| Goal | Needed at USD 29 |
|---|---:|
| USD 100 monthly reserve | 4-5 sales before fees and refunds |
| USD 200 monthly reserve | 8-9 sales before fees and refunds |

### Phase 3: Productized Review

Only after audit or template demand exists:

- AI citation readiness review
- Technical SEO CI setup review
- Programmatic SEO gate review

Do not build SaaS until repeated paid demand appears.

## 30-Day Cash Validation

| Day | Required signal | Action |
|---|---|---|
| 1-3 | Domain, production deployment, GSC/Bing setup | No monetization yet. |
| 4-7 | Crawlable pages and analytics events | Add request-audit intent copy if compliance allows. |
| 8-14 | Tool completion, readiness report copy, template copy, or sample audit view | Add audit intent page and manual GitHub issue path. |
| 15-30 | At least one explicit audit or template interest signal | Prepare payment workflow or stop commercial expansion. |

## Stop Conditions

Stop paid-product expansion if all are true by day 30:

- No indexed core pages.
- No tool completion events.
- No template copy or download behavior.
- No GitHub activity.
- No audit request, email/contact intent, or direct buying signal.

If the stop condition triggers, preserve the site as a public case study and reduce future cost to domain-only.
