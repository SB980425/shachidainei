# Page Templates

## Global Requirements

Every indexable page must include:

- Clear H1.
- One sentence answer block near the top.
- Last updated date.
- Author or site owner reference.
- Breadcrumb.
- Related pages.
- Primary CTA.
- Index/canonical decision.
- Source notes when external facts are used.

## Home Template

Purpose:
- Explain the site as a practical AI website operating system.
- Route users to scorer, templates, checklists, and methodology.

Sections:
1. H1: `AI 建站操作系统：从网站机会评分到 SEO 发布门禁`
2. Answer block: define the site value in 2-3 sentences.
3. Primary actions:
   - Start website opportunity scorer.
   - View SEO repo skeleton.
   - Open AI content quality gate.
4. System map:
   - Opportunity scoring.
   - Site blueprint.
   - Content quality gate.
   - Technical SEO CI.
   - Growth review.
5. First cluster links.
6. Trust links.

CTA:
- `开始评分`
- `复制 Repo 模板`

## Pillar Template

Purpose:
- Define the full system and act as the hub for the first cluster.

Sections:
1. Definition answer block.
2. Who this system is for.
3. Workflow table:
   - Score.
   - Blueprint.
   - Build.
   - Gate.
   - Publish.
   - Review.
4. Decision tree.
5. Links to tool, template, checklists, guide, methodology.
6. Common failure modes.
7. 30/60/90 day operating rhythm.

CTA:
- `用评分器测试你的方向`

## Tool Template

Purpose:
- Let users score one website idea and produce a proceed/pilot/pivot/stop result.

Required inputs:
- Website idea.
- Target language/region.
- Site type.
- Audience.
- Monetization path.
- Data source.
- YMYL risk.
- Weekly execution capacity.

Output:
- Weighted score.
- Decision.
- Hard blockers.
- Next recommended page system.
- CSV export or copyable result.

Analytics:
- `tool_started`
- `tool_completed`
- `tool_result_export`

CTA:
- `复制评分结果`
- `进入站点蓝图`
