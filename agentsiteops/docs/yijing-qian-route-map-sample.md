# 乾为天：处境辨象路线图样本

## 使用边界

本样本用于测试“处境识别”和“行动边界”，不是预测结果。它只回答：当前更像乾卦哪一爻、为什么像、应该守什么、避什么、怎样无咎。

## 乾卦总纲

乾不是单纯的强。乾的核心是：刚健、自强、创始、守正、知时、戒亢。

判断乾卦时，第一问题不是“我强不强”，而是：

```text
我现在的阳气、能力、位置、责任和时机，是否匹配我的行动？
```

若能力和时机不配，强行动就是亢。若能力到了但不见正人，机会会迟。若位高而不退，吉会转悔。

## 如何判断自己在哪一爻

### 初九和九二的区别

- 初九：还没有被正确的人看见，公开行动过早。
- 九二：已经有人能看见你，但你还需要正人提携和校正。

判断问题：

```text
如果现在公开行动，得到的是机会，还是暴露根基不足？
```

得到机会更像九二；暴露不足更像初九。

### 九二和九三的区别

- 九二：重点是出现和见人。
- 九三：重点是责任和戒惧。

判断问题：

```text
我现在最缺的是贵人看见，还是已经被看见后必须承担风险？
```

缺看见是九二；已经承担风险是九三。

### 九三和九四的区别

- 九三：责任已经压上来，需要日夜警惕。
- 九四：机会在前方，可以试探，但还不能定局。

判断问题：

```text
我是在守住已承担的责任，还是在测试下一步能不能跃迁？
```

守责任是九三；测跃迁是九四。

### 九四和九五的区别

- 九四：将飞未飞，必须保留退路。
- 九五：德位相称，已经真正得位。

判断问题：

```text
我现在是否已经拥有合法位置、真实责任和可用资源？
```

没有完整位置和资源是九四；已经德位相称才是九五。

### 九五和上九的区别

- 九五：居高但仍能用贤。
- 上九：居高后不知退，强盛开始变成反噬。

判断问题：

```text
现在继续推进，是扩大正用，还是只是维护自己的高位？
```

扩大正用是九五；维护高位是上九。

### 上九和用九的区别

- 上九：一个人过高，问题在亢。
- 用九：一群强者并起，问题在争首。

判断问题：

```text
当前危险来自我个人过亢，还是团队强者之间争位？
```

个人过亢是上九；群体争首是用九。

## 乾卦记忆锚点

```text
初九：藏
九二：见
九三：惕
九四：试
九五：位
上九：退
用九：不争
```

七个字连起来：

```text
藏、见、惕、试、位、退、不争。
```

这就是乾卦从潜龙到群龙的路线。

## 现实用法

### 吉则如何守

乾卦的吉不是一直冲，而是德、位、时相配。

- 初九守藏。
- 九二守谦。
- 九三守惕。
- 九四守退路。
- 九五守贤。
- 上九守退。
- 用九守不争。

### 凶则如何脱险

乾卦的凶多来自阳气过度。

- 未成而出，退回初九修德。
- 初显而骄，回到九二见大人。
- 责任重而懈，回到九三戒惧。
- 试探变豪赌，回到九四保留退路。
- 得位后独断，回到九五亲贤。
- 亢极不退，立刻让功收敛。
- 群强相争，建立分权和边界。

## 不能输出的内容

- 不输出确定预测。
- 不判断用户必然成功或失败。
- 不给医疗、法律、投资、婚姻决断。
- 不把“吉”解释成保证好结果。
- 不把“凶”解释成命定坏结果。
